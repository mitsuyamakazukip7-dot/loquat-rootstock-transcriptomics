# Apple-rootstock / loquat transcriptomics — analysis source v1.0.0

Local GitHub publication candidate — **NOT PUSHED and NOT yet licensed**.
Authors: Kazuki Mitsuyama; Yukiho Yamamoto.
Paper: Comparative Transcriptomics of Apple Rootstock Responses Identifies Candidate Genes for Loquat Vigor.

## Repository structure
src/R, src/python and src/shell: code used for RNA-seq, DESeq2, apple-centered RBH mapping, local-collinearity filtering, fixed ORA, sensitivity tests, and source-regenerated manuscript Figures 2/4.
verified_pathway_workflow: tested offline reproducible all-gene KEGG GSEA and 20×20 label permutation. Contains minimal source input snapshots required by this small verification.

### Run verified offline workflow
Change into verified_pathway_workflow and execute:
    zsh RUN_FROZEN_AUDIT.sh

Expected: 27/37, conditional fraction 0.395; seeded full 28/38, 0.395; all 147 pathways, 0.420.
Environment used: R 4.5.1; clusterProfiler 4.18.4, limma 3.66.0, fgsea 1.36.2, Python 3.14.7.
The full-gene KEGG mapping is frozen and included. It does not query the live KEGG database.

### Full dataset code
Download the companion processed dataset from Zenodo once its real DOI becomes available. Arrange a project folder with sample manifests, quant.sf, source genome reference FASTA/GFF and result folders in the paths described by the original scripts. Set LOQUAT_PROJECT_ROOT to that project folder; set LOQUAT_SOURCE_DIR for the raw public-SRA acquisition script.

The sources under src have been **path-adapted and syntax checked**, not independently tested on a clean third-party system as one full pipeline. The verified_pathway_workflow is the separately tested executable subset. The historical runner requires SRA Toolkit, Salmon, and original reference sequence indices. Some code expects input data not redistributed (original reference genome annotations and published pear full DEG table).

### Interpretation
Main apple DEG counts: 587, 3815, 1938; 20,795 apple-centered RBH correspondences and selected 269 / 190 / 24 / five candidate tiers. The historical selected 37 pathways show 27 reversals; conditional permutation 0.395. The ortholog-limited 151-pathway ORA table must not be used for full-gene GSEA. The conditional permutation statistic is not selection-adjusted.

CODE LICENSING REMAINS SUBJECT TO AUTHOR CONFIRMATION. No software release or Zenodo software DOI has yet been registered. Do not upload raw FASTQ or mirrored reference genome files into this repository.

## Figure reproduction and dataset workspace adapter (Oct 23 review)

Scripts src/R/rebuild_Figure2.R, rebuild_Figure3.R, rebuild_Figure4.R, rebuild_Figure5.R, and src/python/rebuild_Figure1_and_SuppFigure1.py cover the plots. Use the processed-data-only adapter:

    python3 src/python/prepare_public_analysis_workspace.py --dataset /path/to/Loquat_Processed_Data_v1.0.0 --workspace /path/to/EMPTY_WORKSPACE

Set LOQUAT_PROJECT_ROOT to the new workspace directory and LOQUAT_FIGURE_OUT to a separate figures output directory before running R/Python plotters. The workflow was tested on the author's Mac. Figure 1 generated by the Python script is a corrected-criteria conceptual alternative awaiting final author approval; do not claim it matches the manuscript's current illustration.

This adapter reconstructs a processed-data plot input layout. It does NOT replace separately obtained reference genome FASTA/GFF, transcriptome indices, source pear published tables, or a clean-machine end-to-end raw-read validation. R scripts need ggplot2, patchwork and related plotting dependencies; Figure 1/S1 additionally requires Python numpy/matplotlib.
