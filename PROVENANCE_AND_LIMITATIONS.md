# Scientific / technical provenance and release limitations

Source code was copied from an existing lab Mac project, with local absolute paths replaced by configurable LOQUAT_PROJECT_ROOT / LOQUAT_SOURCE_DIR where recognized. The original scientific calculations and reported results remain in the internal master archive.

1. Full public-SRA re-quantification was verified on the research Mac, with all 51 resulting Salmon quant.sf files bytewise identical to the archived files. This GitHub package has NOT been confirmed as a single-command end-to-end installer on a clean independent PC.
2. The tested, standalone full-gene GSEA/permutation workflow is located at verified_pathway_workflow, with its own frozen input snapshots. The fixed ortholog-limited KEGG ORA table belongs in Zenodo data and is NOT the GSEA full-gene pathway table.
3. The 20,795 gene correspondences are apple-centered reciprocal hits between apple–pear and apple–loquat. A three-pair RBH sensitivity test left all final 24 and five candidates intact.
4. The source main apple study used 3 reported biological replicate groups, but the SRA metadata give the same BioSample identifier for all 36 runs. This does not prove samples are not independent, and tree identity/stage pairing remain unresolved.
5. The pear expression effect sizes were imported from published data rather than generated by a new pear raw RNA-seq reanalysis. Full original pear source datasets and genome mirrors are not redistributed in these packages.
6. Code and processed data will not be considered public until registry URLs/DOIs and coauthor licensing permissions are finalized.

Figure2 and Figure4 R scripts regenerate native vector output; output filenames and paths can be controlled through LOQUAT_FIGURE_OUT when supported.
